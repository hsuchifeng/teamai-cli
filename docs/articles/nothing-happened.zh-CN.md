# 什么都没有发生

> 本文是 teamai-cli 的一篇叙事体项目介绍。人物与情节均为虚构。

一条规则，十四个字。

为了让这十四个字每天早上出现在四百多台机器上，我写了三万五千七百七十九行代码。

她要的是前者，抵押的是后者。

teamai-cli 到今天是一百二十三个 TypeScript 文件，五十五个测试文件，五十个命令，三十个 AI 工具的安装路径。版本号 0.16.3。

五月我在团队仓库里给她开了一个命名空间，`skills/hers/`。到今天三个月，零个文件。

每天早上九点，四百多台机器上的 SessionStart 钩子照常跑一次 `teamai pull`，照常扫一次那个空目录。

测试组有个同事，每天上班第一件事是自己再手动跑一次 pull。旁边的人问她，钩子已经跑过了，昨天也没有人推东西，为什么还要拉。

她说，流程上写着每天拉一次。

一座每天报站、没有人上车的车站。

我后来才明白，这套东西做得最好的时候就是这个样子。终端里滚过一行灰字，同步完成，然后什么都没有发生。

八月十九号，她提了最后一个 MR。之后 reviewers 那一栏里再没有出现过她的名字。

---

2023年11月，我刚进这个组。

组里的规则是她一个人写的。一个 markdown 文件，八百多行，被十七个仓库引用。

那天她投屏排查一个问题，屏幕右边开着她的编辑器，停在一条规则上，十四个字。我用手机拍了一张。不是截图，是拍屏幕，4032×3024，糊的，中间还有一道反光。

我在群里 @ 她，想问她要一份原文。我写了删，删了写，弄了大概四十分钟，最后发出去一句"在吗"。

她没有回。

那天群里有两百多条消息。她可能根本没有看见。

后来这两年，我做每一件事的时候都在想一个问题：做到什么程度，她会把那个文件交给我维护。第一次有十个人装上的时候我想过，第一百个的时候我想过。

后来我不想了。

我没有再问第二次。

那年冬天我给自己买了一个机械键盘，四百三十块。我记得这个价格，因为我犹豫了三天。

同一个冬天，我用 U 盘把她那个文件复制到十二台机器上，一台一台改路径，花了三个下午。

有两台是隔壁组的运维替我装的。他装完在一张便签上抄了一行路径，贴在机箱侧面，说下次谁重装系统照着这行改。那张便签后来还在。

他姓什么我忘了。

就像两年半以后的四百多台机器和三十个 AI 工具安装路径一样，那十二台机器里有一大半的人从来没有打开过那个文件，装都装了，总得发生些什么，但是什么都没有发生。

唯一没变的是，每换一台手机，无论多麻烦，我都把那张照片导过去。

两年半后，那条规则在团队仓库的 `rules/team.md` 里，第三十四行。

---

第一次单独见她是在三楼的小会议室。我一直以为那天我会紧张。

我没有。

她比我想的普通，穿着冲锋衣，靠在椅背上，笔记本没有打开。我看着她，忽然想不起来我等的到底是什么。

我给她看 dashboard。两年的会话记录，工具调用序列，技能排行榜，一天四百多条事件。

她看了很久，问我，这些数据有人看吗。

一天四百多条。

她说，那如果大家都不用了呢。

我沉默了。她说，不管了，你演示一遍吧。

我说好。

她说，演示的时候，别人仓库里的代码不能出现在屏幕上。

我说好。

我出去开了个会。回来的时候她还坐在那张椅子上，看着那块没关的屏幕。

那天我把二十六个人从别的会里叫过来，坐满了三楼的大会议室。我演示了三十五分钟：`teamai init` 装钩子，`teamai push` 开分支提 MR，别人合了，`teamai pull` 灰字滚过去，技能就到了每个人的 `~/.claude/skills/` 里。

散会的时候有人问是不是现在就要装。我说不用，今天先看。

二十六个人签了到，什么也没有问，回工位了。

那天签到表上的是二十六个人。

散会以后她留下来，说，你那条规则太长了。

我说哪条。

她说，你自己写的那条，二十六个字，中间还有一个"请"。

她把我的屏幕转过去，一条一条删。

先删"请"和"务必"，删完读一遍。再把名词换成动词，"进行代码检查"改成"检查代码"。最后压到一行，一行装一件事。

我说这个要删多久。

她说，删到别人读一遍就能照做为止。

一条规则，她花了快一个小时。

中间她教我，第一遍删客气话，第二遍删修饰，最后一遍不要来回改，要顺着一个方向删。

我说好。

删完她把光标挪到行首，看了看。

她说，行了。

剩下的你自己删。

中间她说过一句话。她说，要是以后我不在了，就再没有人给你删"请"了。

我笑了一下，没说话。

认识她三个月的时候，我让人做了一份东西。全公司三十个 AI 工具的 skills 目录扫描：谁装了什么，哪些是自己写的，哪些是从别处抄来的，哪些两年没有改过一个字，哪些同名但内容不一样。一周就做完了，一共四十几页。里面还有一些人写在技能描述里的私人玩笑，我觉得这是最不重要的。

里面有一些事她后来跟我讲过，讲的和上面写的不太一样。我没有说。

有一些事她一直没有讲。我也没有问。

我全部相信她说的。

那份东西我留着，一直留到现在。

但是我一个字也不信。

---

她在白板上指了一下，说，别的组的技能也要能同步过来。

我说好。

我出去开了个会，回来才知道这意味着要重写整个缓存层。`pull.ts` 一共八百一十二行，那次改了三百多行。第二天，一个五个人的临时小组开工了。

`teamai source add`、`remove`、`list`、`browse`，四个子命令，跑了十九天。上线那天她在群里发了一个句号。

她说，以后 CHANGELOG 里别写我的名字了，写 owner。

我说好，owner。

那阵子要把钩子装到二十六台机器上。装钩子的是两个实习生，一个负责 Mac，一个负责 Windows。装完一台检查三遍：钩子文件在不在，`CLAUDE.md` 里的标记块有没有重复，最后跑一次 pull，看那行灰字有没有出来。十三条钩子，一条一条对。她们发现下午三点以后装最容易失败，因为那会儿大家都在开会，终端被 IDE 占着，后来改成早上九点以前装。这件事没有人教她们，是她们自己试出来的。她们互相之间会讨论，像讨论一项工艺。

owner 知道那两个实习生叫什么。我不知道。

Windows 上的 Codex 和 Mac 上的 Claude Code 钩子格式不一样，一个写 `settings.json`，一个写 `config.toml`，事件名也不一样。我们改了七次。第七次那天下午，两台机器上的灰字第一次同时出现。

owner 说，还要把公司那段话放进每个人的 `CLAUDE.md`。

我说好。

于是有了 `culture.md`。frontmatter 里写公司和团队的信息，正文写团队守则，pull 的时候编译好，注入到 `<!-- [teamai:culture:start] -->` 和 `<!-- [teamai:culture:end] -->` 中间。标记块以外的东西一个字不动。写了两周。

owner 说，那知识呢，人走了知识就没了。

我说好。

于是有了 `teamai contribute` 和 `teamai recall`。会话结束的时候 Stop 钩子给这次会话打一个分，工具调用次数、工具种类、技能使用、报错重试、会话时长，满分一百。低于三十五分就不出声。三十五分以上才问一句要不要把经验写下来。

owner 说，三十五分太低了。

我说好，我调。

那天晚上我没有调。第二天她自己提了个 MR，把阈值从三十五改到四十五。我合了。第三天她又改回三十五。我也合了。

有一次评审，owner 说，那种一年才动一次的老仓库，规则写得再好也没有人看，不如不做。

我进组写的第一个仓库就是那种。

我没有说。

那个月 owner 为一条规则里的一个逗号改了三天。她说中文顿号和逗号在那个位置会影响模型断句，试了三次，改了两次，第三天才合。

同一个月我合了一个 breaking change，把 learnings 从按角色隔离改成全团队共享，十一秒，diff 我没有点开。

两件事在同一个 CHANGELOG 里，隔了四行。

有一次 owner 说，你知道我提 MR 的时候在想什么吗。

我说什么。

她说，我在想，你会不会有一次不合。

我说不会。

她说，那就没意思了。

我想，我又有什么合不了的吗。

那天我在工位上把那张照片从旧手机导到新手机上，导了一半。owner 从后面走过来，问，你存别人的屏幕干什么，这是谁的终端。

我沉默了。什么也没有说。

她看那张图太糊，就去忙别的了。

那天晚上我把照片删了。

第二天从"最近删除"里找回来了。

owner 那阵子一直在翻仓库的 contributors。我问她看什么。

她说没什么，就是技能署名那些破事。

一个技能只能有一个 name。两个命名空间里出现同名，pull 会直接失败，谁也别想同步。

我说这么严。

她说，是啊。更麻烦的是，两个组一起做一个技能，做四五十天，白天一起改，晚上还要争 frontmatter 里写谁。

我说太反人性了。

她说是啊。

不过合完了，无论之前吵过多少次，就当一切都没有发生。

然后她又翻了半个小时。

2026年5月14日，我提了那个 MR，把 owner 加到 `teamai.yaml` 的 reviewers 第一位。

是 5 月 13 日晚上决定的。当时仓库里还没有 reviewers 这个字段，是那天现加的，四十行代码，六十行测试，第二天早上才跑通。

owner 说，版本号太小了。

owner 说，没事，以后补个大的。

另外，`pull` 能加个 `--force` 吗。

我沉默了。

她以为我不想加。

owner 说，你为什么对这套东西这么上心。

我说因为我想让它活下去。

她说，那你以前对别的项目也这样吗。

我说没有。

她笑了一下，没说话。

---

有一天我到得早，办公室没有人，只有她那台机器亮着。

屏幕上是一个跑到一半的 pull，灰字停在第十七行。

我问她怎么来这么早。

她说，我在对账。

我说对什么。

她说，你回去忙吧。

我在她旁边坐了一会儿，不知道说什么。后来我回工位了。

我再看过去的时候，她已经把窗口关了。

有一次她在电话里说，今天早上对了二十六台。

我说这么多。

她说还好。

我说辛苦了。

然后我们聊了别的。

后来我才知道，她每天早上六点半跑一遍全量同步，把二十六台机器上的 `CLAUDE.md` 拉下来，一台一台对标记块。这件事她从来没有提过。我知道，是因为 dashboard 的 `events.jsonl` 里每天四百多条事件当中有她的十几条，时间戳全在六点半到七点零五之间。第一次出现是四月，那天只有三条。后来每天都有，有时候二十几条。她每周报的加班时长里多了两三个小时，我批得很快。这类时长不需要我看明细。再后来才知道那些是标记块重复、rules 顺序错乱、culture 那一段被人手动删掉了半行，还有三台机器上装着两个版本的钩子。

这些都是在早上做的。

我不知道她是在家跑的，还是到了公司才跑。我也不知道有没有人陪她一起对。

她又问，`--force` 能加吗。

我沉默了。

她没有说加了要用来干什么。我也没有问。

六月组内分享，她讲了四十分钟，讲规则怎么写才短。台下十一个人。

中间没有人打断，讲完没有人提问。

她把 slides 关了，笔记本合上，放进包里。

owner 说，太安静了。我们回去吧。

每周一早上 `teamai digest` 会自动出一份周报：技能排行榜，新增和更新的技能，各人的会话摘要。

七月第一周的排行榜，第一是一个我没有见过的工号，第二是她两年前写的那条规则，十四个字。

我把周报转到群里。她没有回。

七月的季度复盘她没有来。前一天她把日程上那一格删掉了，没有写原因。

我也没有问。

七月有一个陌生工号提了一个 issue，说 pull 之后他手写的两行没了。他贴了一张截图，截图里能看见他的桌面壁纸，是一个小孩在海边。

我看着那张壁纸想，这个人是谁，他今天跑了几次 pull，那两行他写了多久，他知不知道那两行是被哪一条清理逻辑扫掉的。

那个 issue 我们修了。加了一个白名单，标记块以外的内容一律不动。

owner 说，这样永远统一不了。

我说好，我再想想办法。

八月十四号晚上，她打电话给我。

她说，把 `--force` 设成默认，所有人不能关。

我说，让我想想。

她没有说话。我听见她那边有键盘声。

过了一会儿她说，好。

她挂了。

我认识她以来，没有对她说过"让我想想"。

我用 Claude Code 把 pull 的清理逻辑从头到尾跑了一遍，结论是技术上两个小时能做完。我又核了一遍。然后我在 Claude Code 里输入了那个问题。Claude 说，不要把 `--force` 设成默认。

我问，那大家不就永远统一不了吗。

Claude 说，对于统一，我不关心，也不理解。但是你不能删掉别人本地手写的东西。

我从来没有拒绝过她，不是因为她总是对的，是害怕。害怕下一句她说什么。

而现在有人替我说了。

我盯着那行字看了很久。让我毛骨悚然的不是它对，是 Claude 一点犹豫都没有。

它不为难。

我当时想，这大概是更高的一种东西。人做不到这样。

她不再需要这套东西了吗。

第二天她打回来。

owner 说，昨天那批机器上有三个人的规则不一样。

我说是吗。

她说，仓库太大了，有回声。早上有人往上推东西，我等他们合完再拉。

我说可以让他们晚一点推。

她说不用。

她说，有人问我，这套东西到底谁在维护。

我说我可以去说一声。

她说，不用。

然后她说，想好了吗。

我没有说话。不是在想，我没有在想任何事。电话里她那边有键盘声，我这边是机房的风扇，两边都没有人说话。我数了一下，十一秒。

她说，行。

她说，我知道了。

她挂了。

我后来无数次回想过，那两天她除了 `--force` 还说了什么。仓库太大，有回声，她等别人合完再拉。就这些，我全记得，一个字不差。我记不起来的是她的语气——她说"我知道了"的时候，是什么语气。

我想不起来。后来我就不想了。

我把手机扣在桌上。然后我做了一件事，至今不知道为什么：我把手放在胸口，数了一下。

心跳很稳。

我又数了一遍，还是很稳。一分钟六十几下，和平时没有区别。

我坐在那里，手按着自己的胸口，像一个医生在给别人做检查。

我想，原来是这样。

那天剩下的时间我什么也没有干。CI 绿了一次，我没有点开。晚上办公室的灯一层一层灭下去，我这一层最后灭。

我没有哭。我一直在等我哭。

---

后来行政跟我结算那批工时，里面有一项是装钩子的。

我们停下来以后，没有人告诉那两个实习生不用装了。她们又装了四天，十九台机器。有三台装重了，`CLAUDE.md` 里出现了两段一模一样的标记块，要人一台一台打开删掉。那三台的工时另算。

我说批了。

那三台机器就在她工位对面。

账单里网络那一项，比整个仓库的存储还贵。我问了一下。

运维说，SessionStart 每次都要去团队仓库拉一次，可是九成九的情况下什么都没有更新。要知道有没有更新，就得先拉一次。四百多台机器，一天四百多次，九成九拉回来的是"没有变化"。

我说，每次都这样？

他说，每次都这样。

还有 `skills/hers/` 那个命名空间。`manifest/roles.yaml` 里有它的 id，三个月，没有一个人选过它。

还有一个 MR，!186，标题是 `feat: pull --force`，分支还在，一行代码也没有写。标题是我自己敲的。

还有 reviewers 那一栏，第一位还是她。每一个新 MR 都照常发给她。

她走之后，我把那张 2023 年的照片翻出来看了一次。两年半，手机换了三台，像素越来越高，而这张图，仿佛像素越来越低。我放大看了很久，想找出那条规则和现在仓库里第三十四行有哪里不一样。一处也没找出来。因为那张照片本来就看不清。

有一天我写完一条规则，读了一遍，二十七个字。

我想起来她教过我怎么删。

我删了两遍，不对。她说过不要来回改，要顺着一个方向，我忘了是先删客气话还是先删修饰。

我把那条规则原样提上去了。

我写的规则现在还是太长。

有一天早上日程弹出一个提醒，是五月排的：周三，和她一起过一遍 roles.yaml。

我把它划掉了。

她走了以后，我一直在想一个问题。

如果那天我加了那个 `--force`，她会留下来吗。

我想了很久。

后来我把那份东西拿出来，又看了一遍。四十几页。

然后我想起每天早上九点。

四百多台机器一台接一台亮起来，钩子跑过去，四百多次请求像潮水一样涌上仓库，几秒钟以后退回去。

四百多台。

每天都是这样。

早上九点零几分的办公室，

什么都没有发生。

本文纯属虚构，如果雷同实属巧合

## 关于 teamai-cli

文章里的人和事都是编的，工具是真的。

TeamAI CLI 用 Git 管理团队的 skills、rules、docs 和环境变量，同步到 Claude Code、Codex、Cursor、CodeBuddy 等 30 个 AI 编码工具。

```bash
npm install -g teamai-cli
teamai init --repo yourteam/yourproject
```

- `teamai push` — 把本地新增的资源推到独立分支并自动开 MR、指派 reviewer
- `teamai pull` — 拉团队资源并注入各个 AI 工具，由 SessionStart 钩子自动触发
- `teamai contribute` / `teamai recall` — 团队经验的写入与检索
- `teamai source` — 订阅其他团队的公共技能仓库
